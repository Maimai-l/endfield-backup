# Design System 规范（功能性 Web App）

Sep 30, 2026 · @MM

可视化展示见仓库根目录 `showcase.html`，以其为准；本文档与之不一致时按 showcase 修正。本规范以现有 token（`tokens/colors.css`、`tokens/motifs.css`）和源站控件 CSS（`css/controls.css`）为取值来源，按功能性 Web App 的需要重新组织。源站没有的部分（表单控件、表格、功能色、深色模式语义层）在此补齐。所有对比度数值按 WCAG 2.x 相对亮度公式计算。

**全局规则**

1. 颜色只使用源站色值；例外为提醒角标橙色 `#fb7803` 与错误红 `#d03c34`，均取自游戏界面。不使用浅色衬底，不使用半透明叠加（对话框遮罩除外）。
2. 品牌黄 `#fffa00` 只作纯色填充，其上文字为墨色 `#191919`；浅色面上不作文字、边框或焦点环。选中的列表项、侧边菜单项和主标签用纯黄色块；勾选类控件在浅色模式为墨色填充配黄色标记，深色模式反转。
3. 45° 警示条纹只用于危险确认对话框标题栏、警告色条与不确定进度。
4. 按钮上不使用 unicode 字符作图标，图标一律为 SVG。
5. 源站按钮的标志性竖条只用于纯文字的主要、强调、危险按钮：静止为 2px 竖条，悬停时变为指向右侧的三角，同时圆角 2px → 6px。带前置图标的按钮与次要、幽灵按钮不显示竖条，由图标执行动作（加号转 90°、箭头右移、刷新转一周）。

## 颜色

全部色值取自源站 CSS；例外有两个，均取自游戏界面：提醒角标橙色 `#fb7803`（系统界面），错误红 `#d03c34`（战斗界面敌方血条）。不使用浅色衬底、不使用半透明叠加（对话框遮罩除外）。

| 等级 | 色值 | 用途 |
| --- | --- | --- |
| Y-300 | `#fffa00` | 主色：强调按钮、勾选标记、选中的列表与侧边菜单、主标签选中块、深色模式焦点环 |

| Y-500 | `#e6de01` | 强调按钮按下 |

黄色只作纯色填充或深色面上的文字，不做浅色衬底，也不在浅色面上作文字色。

### 功能色

| 类型 | 色值 | 呈现方式 |
| --- | --- | --- |
| 成功 | `#00ffa2`（源站色条绿） | 纯色标记：图标、左侧色条、状态点；外沿 1px 墨色描边 |
| 错误 | `#d03c34`（游戏战斗界面血条红） | 纯色标记、危险按钮底色（白色文字）、错误边框、浅色面上的错误说明文字 |

| 提醒角标 | `#fb7803` | 9px 橙色菱形，位于图标或标签右上角 |

## 交互状态与控件

各控件的变体、尺寸、状态、引用的 token、键盘操作与 HTML 结构，统一以 `showcase.html` 为准：

- 交互状态：`showcase.html#states`
- 基础操作（按钮、胶囊按钮、图标按钮、圆形关闭按钮、链接）：`#basic`
- 表单输入：`#form`
- 反馈与提示：`#feedback`
- 导航（主标签栏、标签页、分页器、面包屑与路径、导航栏）：`#navigation`
- 内容展示（条目卡片、信息卡片、标签与提醒角标、头像、列表与侧边菜单、表格、分隔线、空状态）：`#display`
- 主控台（取自游戏主菜单的三维环形面板，按功能分类：布局 = 球面布局与组合示例；导航 = 立体入口磁贴；操作 = 弧形主操作磁贴；读数 = 环形仪表、额度胶囊、指标徽章；身份 = 账户卡）：`#console`。面板为圆角、半透明磨砂材质，只用于深色场景。

# UI kit — Marketing site (generic)

Interactive sample site in the Endfield industrial style, composed from the design-system components. All content is placeholder — no game brand marks, characters, or copy.

- `index.html` — shell: fixed `NavSidebar` + screen switcher (首页 / 档案 / 情报)
- `Screens.jsx` — `EfHomeScreen` (hero, HomeButton, DownloadTiles), `EfArchiveScreen` (AvatarChips, LabelTags, DividerBand), `EfNoticeScreen` (NoticeCard, TitleBlock, Pagination)

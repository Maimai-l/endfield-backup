# Icons

- 全部为 16 网格的单色 SVG，墨色 `#191919`，1.6px 描边，直角端点与斜接转角。文件与 `bundle.js` 内置雪碧图同名同形；在页面中优先用 `<svg class="ic"><use href="#…"/></svg>`，它随文字颜色变化，`<img>` 只能显示墨色。
- `i-*`：界面图标。`i-chev-*` 为源站翻页按钮的粗折线箭头，`i-arrow-dr` 为源站区块标题的折角箭头，`i-arrow-r` 由它旋转得到。
- `k-*`：键盘方向键，用于快捷键说明。
- `n-*`：源站侧边导航图标。
- `s-*`：状态标记，实心色块加墨色描边：成功为黄色圆形 `#fffa00`（`color-success`）、警告为橙色三角 `#fb7803`（`color-warning`）、错误为红色八边形 `#d03c34`（`color-error`，内部叉为白色）、信息为墨色圆形 `#191919`（`color-info`，内部符号为白色）。`bundle.js` 中的同名图标按这些 token 着色，深色主题下随之变化。

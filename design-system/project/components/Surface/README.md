# Surface

大色面与磨砂玻璃。黄色或墨色铺满一个区域作为底，信息面板与固定导航以磨砂玻璃浮在色面之上。

## 何时使用

- 黄色整面：页面中需要最先被看到的头图区，例如版本发布、阶段总结。一个页面最多一块。
- 墨色整面：需要与白色页面拉开层次的独立区域，例如归档、历史记录的整块列表。
- 磨砂玻璃：浮在色面上的信息面板，以及固定在顶部、内容从下方滚过的导航栏。

## 使用方提供

色面类 `surf surf--brand|surf--ink`；可选纹理类 `surf--contour` 与巨型数字 `surf-num`（只用于黄色整面）；可选黄色竖条 `surf-col`（只用于墨色整面）；玻璃类 `glass`，放在色面内部并由使用方绝对定位。

## 规则

- 色面不随明暗主题变化。色面与玻璃在内部重新定义文字、主要按钮、选中与进度的颜色 token，放入其中的组件无需另加样式。
- 黄色整面上的文字、图标、按钮全部为墨色；主要按钮为墨底白字，左侧竖条为黄色。不在黄色整面上放红色、橙色标记。
- 黄色整面可以用源站等高线纹理 `wave-bg.png` 与 `font-giant` 巨型数字作图形。巨型数字的平顶与左侧眉题的平顶对齐，右边与玻璃面板右边对齐，可被色面边缘或玻璃面板截断。
- 墨色整面可加一条贯通上下的黄色竖条（源站装饰竖条），竖条左边与导航标题左边对齐，列表从竖条右侧 32 开始，并与导航项左边对齐。
- 玻璃只用一种：黑色 80% 加 8px 背景模糊，圆角 4，不加描边与阴影。玻璃内正文为白色，次要文字 `#a6a6a6`，进度与选中为品牌黄。
- 玻璃只放在色面之上。白色、灰色页面底上不用玻璃，背后没有可透出的颜色；也不用白色玻璃，白色玻璃叠在黄色上会形成浅黄底。
- 一个色面上最多一块玻璃面板；玻璃面板不叠放。
- 左右两列共用上下两条边线：眉题与巨型数字的顶边对齐，左列按钮的底边与玻璃面板的底边对齐，内边距统一为 32。

## 规格

- **尺寸**：色面内边距 32，圆角 4；头图区高 320；玻璃面板宽 280，内边距 20/24/24；固定导航高 56；巨型数字 400，墨色
- **Token**：`--y-300 --glass-bg --glass-blur --radius-md --font-giant --font-en --font-bold`
- **可访问性**：巨型数字只作图形，加 `aria-hidden="true"`；固定导航用 `nav`，当前项加 `aria-current="page"`

## 结构

```html
<section class="surf surf--brand surf--contour">
  <span class="surf-num" aria-hidden="true">04</span>
  <div>…眉题、标题、正文、主要按钮…</div>
  <div class="glass">…进度条与说明…</div>
</section>

<section class="surf surf--ink">
  <span class="surf-col" aria-hidden="true"></span>
  <div>…列表…</div>
  <nav class="glass">…标题与导航项…</nav>
</section>
```

# Surface

大色面与磨砂玻璃。黄色或墨色铺满一个区域作为底；磨砂玻璃只用在墨色整面上，作为内容从下方滚过的固定导航。

## 何时使用

- 黄色整面：页面中需要最先被看到的头图区，例如版本发布、阶段总结。一个页面最多一块。
- 墨色整面：需要与白色页面拉开层次的独立区域，例如归档、历史记录的整块列表。
- 磨砂玻璃：墨色整面顶部的固定导航，列表从导航下方滚过。

## 使用方提供

色面类 `surf surf--brand|surf--ink`；可选纹理类 `surf--contour` 与巨型数字 `surf-num`（只用于黄色整面）；玻璃类 `glass`，放在墨色整面内部并由使用方绝对定位。

## 规则

- 色面不随明暗主题变化。色面与玻璃在内部重新定义文字、主要按钮、选中与进度的颜色 token，放入其中的组件无需另加样式。
- 黄色整面上的文字、图标、按钮、进度全部为墨色；主要按钮为墨底白字，左侧竖条为黄色；进度轨道为 `y-500`。不在黄色整面上放红色、橙色标记。
- 黄色整面可以用源站等高线纹理 `wave-bg.png` 与 `font-giant` 巨型数字作图形。巨型数字固定 400，只放在文字列右侧，与文字列相隔至少 32，不与任何文字或控件重叠；平顶与眉题平顶对齐，右边距色面 32。色面宽度不足 808 时不显示巨型数字，不缩小。
- 玻璃不放在黄色上：深色玻璃会把黄色压成橄榄色，模糊后的墨色图形会变成污块；白色玻璃会形成浅黄底。黄色整面上需要分区时用墨色实底。
- 玻璃只放在背后只有黑、白、灰内容的墨色整面上。白色、灰色页面底上也不用玻璃。
- 玻璃只用一种：黑色 80% 加 8px 背景模糊，不加描边与阴影。一个色面上最多一块玻璃。
- 内边距统一为 32；固定导航的标题宽 96，导航项左边与列表标题列左边对齐。

## 规格

- **尺寸**：色面内边距 32，圆角 4；头图区高 320；固定导航高 56，当前项下方 2px 黄色；列表行高 48；巨型数字 400，墨色
- **Token**：`--y-300 --y-500 --glass-bg --radius-md --font-giant --font-en --font-bold`
- **可访问性**：巨型数字只作图形，加 `aria-hidden="true"`；固定导航用 `nav`，当前项加 `aria-current="page"`

## 结构

```html
<section class="surf surf--brand surf--contour">
  <span class="surf-num" aria-hidden="true">04</span>
  <div>…眉题、标题、正文、进度、主要按钮…</div>
</section>

<section class="surf surf--ink">
  <div>…列表…</div>
  <nav class="glass">…标题与导航项…</nav>
</section>
```

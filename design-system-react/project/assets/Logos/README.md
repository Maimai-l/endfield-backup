# Logos

- `endfield-wordmark.svg`：ENDFIELD 字标，墨色 `#191919`，用于浅色面。比例 1902 比 254，含前缀两道斜线。
- `endfield-wordmark-white.svg`：同一字标，白色 `#ffffff`，用于深色面与品牌黄以外的深色底。
- 需要随主题变色时，把路径内联为 `<svg>` 并设 `fill: var(--color-text-primary)`。
- 只整体缩放，不拉伸、不改字距、不描边、不加阴影，不放在品牌黄上用白色版本；最小宽度 120px；四周留出至少与斜线等宽的空白。
- 不要用任何字体排出 “ENDFIELD” 来代替字标。

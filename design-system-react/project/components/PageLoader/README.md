# PageLoader

整页加载层，按源站首屏加载重建：纵向进度条与跟随读数，完成后黄色矩形沿垂直于进度条的方向覆盖再淡出。

## 何时使用

应用首次启动、切换工作区、整页数据重载，且预计超过 1 秒。

## 使用方提供

`orientation`（vertical、horizontal）、`label`、`appTitle`；由外部控制进度时传 `progress`（0 至 100），省略时自动演示一次；`replayKey` 改变时重新演示；`onDone`。

## 规则

- 容器宽度小于 480 时自动改为底部横向进度条。
- 加载层固定为源站的深色底 #141414，与页面主题无关；进度条与读数为品牌黄 #fffa00，装饰标记为 #666。
- 完成覆盖与进度条方向垂直：纵向进度条时黄色矩形自左向右覆盖，横向进度条时自下向上覆盖。

## 规格

- **用途**：阻塞整页且预计超过 1 秒的加载：应用首次启动、切换工作区、整页数据重载。局部区域的加载使用加载指示器
- **尺寸**：纵向：左侧进度条宽 10，自上而下填充；读数跟随填充末端，距左 25，数值 35 SansMedium，百分号 26，上方为宽 4、高 15 的竖条标记，末端处为两枚 4px 灰色方块，下方为 11 号状态文字。横向：进度条距底 64，通栏，高 8，自左向右填充；读数在进度条上方跟随填充末端，100% 时右端距边 16；灰色方块与状态文字在进度条下方。完成后黄色矩形覆盖整个加载层，纵向时自左向右、横向时自下向上（0.6 秒，缓动 cubic-bezier(1, 0, .7, 1)，延迟 0.3 秒），1 秒后整层在 0.5 秒内淡出，露出页面
- **Token**：`--y-300 --font-medium`（深色底 #141414 与装饰色 #666 为源站固定值）
- **键盘**：不可聚焦；加载层使用 `role="progressbar"` 并更新 `aria-valuenow`，淡出后设为不可见，焦点移到页面主标题

## 结构

```jsx
const { PageLoader } = window.Endfield;

<PageLoader label="正在载入工作区" progress={progress} onDone={show} />
```

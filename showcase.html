控件盘点

参考 ReEnd-Components 的调整 Reference

ReEnd-Components 是按终末地游戏界面制作的 React 组件库，共 75 项以上组件，深色优先。本页采纳其中适用于功能性应用的做法，数值仍以源站为准；不适用的做法列在右侧并说明原因。

采纳

  • 菱形标记单选框、开关滑块、状态点、步骤条与时间线节点统一使用菱形；复选框保留对勾，以便与单选框区分
  • 旋转菱形加载指示器替换原来的圆环，按钮、开关、下拉选择的加载态共用
  • 卡片角括号可交互卡片在悬停与选中时显示左上、右下两处角括号
  • 基础 token 补全新增字体、字号、间距、圆角、阴影、动效、层级与图标一节
  • 扩展控件 6 项数字输入、步骤条、折叠面板、操作菜单、文件上传、时间线
  • 键盘说明与 HTML 结构每个控件列出键盘操作，并可展开查看示例的 HTML 结构

未采纳

  • 切角按钮（clip-corner）clip-path 会裁掉焦点环与阴影，并与源站按钮 2px → 6px 的圆角悬停冲突
  • 禁用态整体透明度 40%文字对比度随所在背景变化，无法保证；本规范使用独立的禁用色
  • 浅色模式主色改为深黄配白字ReEnd 浅色主色为 hsl(42 90% 42%)，失去品牌黄；本规范保持黄色填充配墨色文字
  • 悬停上移 1px 与黄色外发光源站只使用环境阴影，状态变化不产生位移
  • 界面文字全部使用 Orbitron 大写Orbitron 不含中文字形；英文标签继续使用源站 Gilroy
  • GlitchText、DataStream 等装饰组件不属于功能控件，需要时只在营销页面使用
